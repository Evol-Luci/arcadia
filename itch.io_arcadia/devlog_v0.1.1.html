EVOL DIGITAL PRODUCTIONS  ·  PATCH LOG
v0.1.1
STABILITY PASS
[ LARGE-LIBRARY SCANS  //  LIVE PROGRESS  //  CONTROLLER + SAVE FIXES ]

A maintenance release that hardens the parts you actually touch every day — indexing, launching, and saves. No new modules, just fewer ways for the existing ones to trip. Arcadia is still the conductor, not the orchestra.

>_ FIXED
SCANS NO LONGER STALL

A disc-grouping bug could abort indexing partway through on Sega CD / Mega‑CD sets — the scan looked frozen near the end. Big libraries (10,000+ ROMs) now index cleanly to completion.

DISCONNECTED-DRIVE GUARD

Launching a game from an unplugged external drive now shows a clear “reconnect the drive” message instead of handing the emulator a missing file and letting it crash.

SAVES FOR COMPRESSED ROMS

Savestates for games stored as .zip / .7z now resolve to the right files — states written against the extracted ROM are discovered in place.

WIDER CONTROLLER FIX

The Bluetooth controller compatibility fix (xpadneo / SDL backend) now applies automatically across every standalone emulator, not just a handful — your pad just works.

>_ IMPROVED
  • Live progress — the sidebar now shows real-time progress for library scans and box-art fetches, clears itself when done, and surfaces failures instead of spinning forever.
  • Settings, organized — the Settings screen is now split into tabs so the controls are easier to find.
  • Steadier indexing — the scanner writes in bounded batches under SQLite WAL, so a long indexing run stays responsive and shows partial progress.
  • Quieter recovery — stale profile references self-heal, and archive extractions persist across launches so saves keep resolving.
